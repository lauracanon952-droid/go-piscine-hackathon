# Go Piscine & Hackathon Projects (Digiemmes Academy)

A collection of algorithmic challenges and team Hackathon projects built in **Go (Golang)** during an intensive peer-to-peer coding bootcamp (01Edu curriculum) in Abidjan.

## 🚀 Projects Included
* **`/sudoku` (Sudoku Solver):** A command-line application that validates and solves 9x9 Sudoku boards using recursive backtracking algorithms (`os.Args` parsing, constraint validation).
* **`/3.quad` (Quad A-E):** Command-line geometric pattern generators built in Go using rune manipulation and nested loops.

## ⚙️ How to Run
```bash
# Run the Sudoku Solver
cd sudoku
go run main.go ".96.4...1" "1...6...4" "5.481.39." "..795..43" ".3..8...." "4.5.23.18" ".1.63..59" ".59.7.83." "..359...7"
```
